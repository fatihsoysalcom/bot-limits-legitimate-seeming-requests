# Bot Limits Legitimate Seeming Requests

This Python script simulates a simple chatbot that struggles with requests that appear legitimate but exceed its programmed knowledge or capabilities. It demonstrates how seemingly reasonable questions can expose a bot's limitations in areas like abstract concepts, subjective opinions, or real-world actions.

## Language

`python`

## How to Run

Run the script using 'python main.py'. Type 'quit' to exit.
